# Схема журнала брокера

Журнал брокера (`log_path` в конфиге, на хосте обычно `/var/log/tmb/broker.log`) это JSONL: одно событие на строку, объект JSON с ключами в алфавитном порядке. Документ перечисляет все события, которые пишет `tmb-broker`, и все их поля с типами. Регистр событий в коде (`src/cmd/tmb-broker/audit.go`) и этот документ сверяет Go-тест `TestAuditSchemaDoc`; `TestAuditSchemaCode` сверяет регистр с тем, что код реально пишет. Событие или поле не из документа, как и документированное поле, которого код не пишет, роняют тест.

Текущая версия схемы: `2`.

Версия `2`: полный nonce вместо первых 12 символов, `hash` в `request`, `deny` и `approval`, `client_gone` в `exec_exit`; события сокета одобряющих пишут `approver_uid` и `approver_pid` вместо полей запросчика.

## Правила

- Каждое событие несёт поле `schema`. Изменение набора полей или типа поля существующего события поднимает `schema`; новое событие версию не меняет. Набор полей каждой выпущенной версии заморожен в тесте `TestAuditSchemaVersion`: изменённое событие без новой версии роняет тест. Консьюмер, встретивший незнакомую версию, должен считать формат неизвестным.
- Поле из таблицы события может отсутствовать в конкретной строке: условия указаны в описании. Поля запросчика взаимоисключающие: `requester_uid` и `requester_pid` на локальном пути (SO_PEERCRED), `requester_fp` на пути песочницы (TLS). События сокета одобряющих несут вместо них `approver_uid` и `approver_pid`.
- Типы: `string`, `integer`, `boolean`, `array of string`, `array of integer`, `object of string` (объект со строковыми значениями), `any` (значение поля конфига как есть). `array of string` может быть `null`, если запрос не прислал массив.
- Событие пишется и синхронизируется на диск (`fsync`) до ответа клиенту. Ошибка записи или `fsync` переводит журнал в состояние «недоступен»: брокер отвечает новым соединениям `audit_unavailable`, ничего не выполняя, уже запущенные команды дорабатывают, а строки событий, включая `exec_exit`, уходят в stderr брокера (резерв) в том же формате. Выход из состояния: успешный reopen по SIGHUP.
- SIGHUP перечитывает конфиг и открывает файл журнала заново по пути `log_path` (logrotate с `postrotate` на `systemctl reload`) до событий этого reload, поэтому они уже в новом файле. Неудачный reopen тоже переводит журнал в «недоступен».
- Запись, оборванная ошибкой или падением брокера, может оставить в файле обрывок строки без перевода строки. Открывая файл (старт, reopen), брокер завершает такой обрывок переводом строки: следующее событие начинается с новой строки и разбирается. Консьюмер пропускает строку, которая не разбирается как JSON; при ошибке записи целое событие из неё есть в stderr брокера.

## Общие поля

| Поле | Тип | Описание |
|---|---|---|
| `schema` | integer | версия схемы, сейчас `2` |
| `ts` | string | время события, UTC, RFC 3339 с наносекундами |
| `event` | string | имя события, один из заголовков ниже |

## Жизненный цикл брокера

### `broker_start`

Брокер открыл сокеты и начинает принимать запросы.

| Поле | Тип | Описание |
|---|---|---|
| `pid` | integer | pid брокера |
| `socket` | string | путь сокета запросчиков |
| `mode` | string | режим одобрения: `queue`, `manual`, `mock-approve`, `mock-deny`, `mock-timeout` |
| `ttl_seconds` | integer | TTL одноразового токена |
| `allowed_requester_uids` | array of integer | allowlist uid на локальном пути |
| `allowed_requester_keys` | array of string | allowlist отпечатков ключей песочниц |
| `tls_addr` | string | адрес TLS-листенера; только если он настроен |

### `broker_stop`

Брокер получил SIGTERM или SIGINT и завершается.

| Поле | Тип | Описание |
|---|---|---|
| `pid` | integer | pid брокера |

### `tls_listen`

TLS-листенер для песочниц слушает.

| Поле | Тип | Описание |
|---|---|---|
| `addr` | string | адрес листенера |

### `reload`

SIGHUP применил новый конфиг.

| Поле | Тип | Описание |
|---|---|---|
| `pid` | integer | pid брокера |
| `changed` | array of string | изменившиеся перезагружаемые поля конфига по алфавиту; `tls_material`, если изменились байты сертификата брокера или CA |
| `ignored` | array of string | изменившиеся поля, которые применяются только при старте |

### `reload_failed`

SIGHUP не применил конфиг: конфиг невалиден или TLS-файлы не загружаются. Действует прежний конфиг.

| Поле | Тип | Описание |
|---|---|---|
| `pid` | integer | pid брокера |
| `error` | string | причина |

### `reload_ignored_field`

При reload изменилось поле, которое применяется только при старте; одно событие на поле.

| Поле | Тип | Описание |
|---|---|---|
| `field` | string | имя поля конфига |
| `running` | any | значение, с которым брокер работает |
| `config` | any | значение в новом конфиге |

### `audit_unavailable`

Журнал стал недоступен: запись, `fsync` или reopen завершились ошибкой. Пишется только в stderr, потому что файл журнала писать нельзя.

| Поле | Тип | Описание |
|---|---|---|
| `pid` | integer | pid брокера |
| `path` | string | путь журнала |
| `error` | string | причина |

### `claim_gc`

Проход очистки истёкших claim-файлов (при старте и раз в час).

| Поле | Тип | Описание |
|---|---|---|
| `removed` | integer | сколько файлов удалено |
| `skipped` | integer | сколько файлов оставлено (по каждому событие `claim_gc_skipped`) |
| `error` | string | ошибка обхода каталога; только при ошибке |

### `claim_gc_skipped`

Claim-файл, который проход очистки оставил на месте.

| Поле | Тип | Описание |
|---|---|---|
| `file` | string | имя файла |
| `error` | string | почему файл не удалён |

## Соединения и идентичность

### `peercred_error`

SO_PEERCRED не удалось прочитать; соединение отклонено.

| Поле | Тип | Описание |
|---|---|---|
| `error` | string | причина |
| `socket` | string | `approver` для сокета одобряющих; на сокете запросчиков поля нет |

### `tls_handshake_failed`

TLS-рукопожатие не прошло: нет сертификата, чужой CA, истёкший сертификат. Отпечатка ещё нет.

| Поле | Тип | Описание |
|---|---|---|
| `remote` | string | адрес клиента |
| `error` | string | причина |

### `tls_no_client_cert`

Рукопожатие прошло без клиентского сертификата (при обязательном сертификате недостижимо, соединение отклоняется).

| Поле | Тип | Описание |
|---|---|---|
| `remote` | string | адрес клиента |

### `requester_denied`

Запросчик не в allowlist; запрос не читается.

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid запросчика (локальный путь) |
| `requester_pid` | integer | pid запросчика (локальный путь), только для показа |
| `requester_fp` | string | отпечаток ключа песочницы (путь песочницы) |
| `reason` | string | `requester_not_allowed` |

### `bad_frame`

Кадр запроса не прочитан (обрыв, превышение размера); на сокете запросчиков или одобряющих.

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid (локальный путь) |
| `requester_pid` | integer | pid (локальный путь) |
| `requester_fp` | string | отпечаток ключа (путь песочницы) |
| `approver_uid` | integer | uid (сокет одобряющих) |
| `approver_pid` | integer | pid (сокет одобряющих) |
| `error` | string | причина |

### `bad_request`

Кадр прочитан, но это не JSON запроса.

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid (локальный путь) |
| `requester_pid` | integer | pid (локальный путь) |
| `requester_fp` | string | отпечаток ключа (путь песочницы) |
| `error` | string | причина |

## Запрос и решение

### `request`

Запрос прочитан, до проверок политики.

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid (локальный путь) |
| `requester_pid` | integer | pid (локальный путь) |
| `requester_fp` | string | отпечаток ключа (путь песочницы) |
| `transport` | string | `unix` или `tls` |
| `type` | string | `exec`, `approve`, `claim` или неизвестный тип как есть |
| `executable` | string | путь исполняемого файла из запроса |
| `argv` | array of string | argv из запроса |
| `cwd` | string | cwd из запроса |
| `uid` | integer | целевой uid из запроса |
| `env` | object of string | запрошенные переменные окружения |
| `nonce` | string | nonce целиком (до 128 символов; длиннее только у запроса, отклонённого `nonce_invalid`) |
| `hash` | string | хеш точного запроса, по нему связываются события одного запроса |
| `claim_token` | string | предъявленный токен (`claim`), иначе пустая строка |

### `deny`

Запрос отклонён; ничего не выполнено.

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid (локальный путь) |
| `requester_pid` | integer | pid (локальный путь) |
| `requester_fp` | string | отпечаток ключа (путь песочницы) |
| `executable` | string | путь исполняемого файла из запроса |
| `argv` | array of string | argv из запроса |
| `nonce` | string | nonce целиком (до 128 символов; длиннее только у запроса, отклонённого `nonce_invalid`) |
| `hash` | string | хеш точного запроса |
| `reason` | string | стабильный код отказа (`shell_policy`, `token_consumed_replay`, `audit_unavailable` и другие) |
| `detail` | string | пояснение |

### `queued`

Запрос встал в очередь одобрений (режим `queue`).

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid (локальный путь) |
| `requester_pid` | integer | pid (локальный путь) |
| `requester_fp` | string | отпечаток ключа (путь песочницы) |
| `item` | string | id элемента очереди |
| `hash` | string | хеш точного запроса |
| `executable` | string | realpath исполняемого файла |
| `argv` | array of string | argv |
| `cwd` | string | realpath cwd |
| `nonce` | string | nonce целиком (до 128 символов; длиннее только у запроса, отклонённого `nonce_invalid`) |

### `approval_timeout`

Элемент очереди не дождался решения за `approval_wait_seconds`.

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid (локальный путь) |
| `requester_pid` | integer | pid (локальный путь) |
| `requester_fp` | string | отпечаток ключа (путь песочницы) |
| `item` | string | id элемента очереди |
| `wait_seconds` | integer | срок ожидания этого элемента |

### `request_abandoned`

Запросчик разорвал соединение, пока его запрос ждал в очереди. Запрос не выполняется, даже если решение одобряющего пришло одновременно с обрывом.

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid (локальный путь) |
| `requester_pid` | integer | pid (локальный путь) |
| `requester_fp` | string | отпечаток ключа (путь песочницы) |
| `item` | string | id элемента очереди |
| `wait_seconds` | integer | срок ожидания этого элемента |

### `approver_denied`

К сокету одобряющих подключился uid не из `approver_uids`; очередь ему не показана.

| Поле | Тип | Описание |
|---|---|---|
| `approver_uid` | integer | uid подключившегося |
| `approver_pid` | integer | pid подключившегося |
| `reason` | string | `approver_not_allowed` |

### `decision_rejected`

Решение одобряющего не принято: элемента нет, он уже решён, хеш не совпал или одобряющий сам запросил этот запрос.

| Поле | Тип | Описание |
|---|---|---|
| `approver_uid` | integer | uid одобряющего |
| `approver_pid` | integer | pid одобряющего |
| `item` | string | id элемента из решения |
| `reason` | string | `no_such_item`, `already_decided`, `decision_mismatch` или `approver_is_requester` |

### `queue_list_failed`

Список очереди не отправлен одобряющему (ошибка записи кадра).

| Поле | Тип | Описание |
|---|---|---|
| `approver_uid` | integer | uid одобряющего |
| `approver_pid` | integer | pid одобряющего |
| `error` | string | причина |

### `approval`

Итог одобрения запроса.

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid (локальный путь) |
| `requester_pid` | integer | pid (локальный путь) |
| `requester_fp` | string | отпечаток ключа (путь песочницы) |
| `mode` | string | режим одобрения |
| `approver` | string | идентичность одобряющего (`uid:1500`) в режиме `queue`, `mode:<режим>` в остальных |
| `decision` | string | `approve` или `deny` |
| `result` | string | `granted` или `denied` |
| `reason` | string | код отказа; пустая строка при одобрении |
| `executable` | string | путь исполняемого файла из запроса |
| `argv` | array of string | argv |
| `nonce` | string | nonce целиком (до 128 символов; длиннее только у запроса, отклонённого `nonce_invalid`) |
| `hash` | string | хеш точного запроса |

## Выполнение

### `claim`

Одноразовый токен и nonce погашены на диске, одобрение найдено; дальше выполнение.

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid (локальный путь) |
| `requester_pid` | integer | pid (локальный путь) |
| `requester_fp` | string | отпечаток ключа (путь песочницы) |
| `token` | string | id токена |
| `hash` | string | хеш точного запроса |
| `nonce` | string | nonce целиком (до 128 символов; длиннее только у запроса, отклонённого `nonce_invalid`) |
| `executable` | string | realpath исполняемого файла |
| `result` | string | `ok` |

### `exec_start`

Команда сейчас будет запущена. Без записи этого события на диск команда не запускается (отказ `audit_unavailable`).

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid (локальный путь) |
| `requester_pid` | integer | pid (локальный путь) |
| `requester_fp` | string | отпечаток ключа (путь песочницы) |
| `token` | string | id токена |
| `executable` | string | одобренный realpath |
| `argv` | array of string | argv, ровно как одобрен |
| `cwd` | string | realpath cwd |
| `uid` | integer | целевой uid |
| `env_count` | integer | число переменных окружения процесса |
| `exe_via_fd` | boolean | запуск через закреплённый дескриптор (`/proc/self/fd/N`, Linux) |
| `exe_dev` | integer | устройство одобренного исполняемого файла |
| `exe_ino` | integer | inode одобренного исполняемого файла |
| `cwd_verified` | boolean | идентичность cwd перепроверена перед запуском |
| `cwd_via_fd` | boolean | cwd задан через удерживаемый дескриптор каталога |

### `exec_fail`

Процесс не запустился.

| Поле | Тип | Описание |
|---|---|---|
| `token` | string | id токена |
| `error` | string | причина |

### `exec_exit`

Команда завершилась. Если журнал стал недоступен, пока команда работала, событие уходит в stderr брокера.

| Поле | Тип | Описание |
|---|---|---|
| `requester_uid` | integer | uid (локальный путь) |
| `requester_pid` | integer | pid (локальный путь) |
| `requester_fp` | string | отпечаток ключа (путь песочницы) |
| `token` | string | id токена |
| `executable` | string | одобренный realpath |
| `exit_status` | integer | код выхода; `128+N` при завершении сигналом N |
| `duration_ms` | integer | длительность в миллисекундах |
| `client_gone` | boolean | клиент перестал принимать вывод (обрыв или запись дольше 30 секунд); остаток вывода отброшен, команда доработала |
