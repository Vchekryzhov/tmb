# TMB

Глоссарий Tool Mediation Broker: словарь посредничества между агентом в песочнице OpenShell и привилегированным выполнением команд на принимающем хосте. Здесь зафиксированы договорённости о смысле слов, а не факты об уже написанном коде; деталей реализации нет.

## Language

**TMB (Tool Mediation Broker)**:
Посредник между агентом в песочнице OpenShell и привилегированным выполнением команд на принимающем хосте: агент просит, человек одобряет, брокер допускает не более одной попытки запуска по одобренному запросу. Неофициальная расшифровка: «trust me brother».

**Агент**:
Программа в песочнице, которая обращается к TMB через tmb-клиент за выполнением команды на хосте. OpenCode один из возможных агентов; конкретный агент не определяет контракт TMB.

**OpenShell**:
Среда изоляции агента, которая контролирует доступ к файлам и сетевым соединениям, включая соединение tmb-клиента с брокером. Одобрение и выполнение запрошенной команды на принимающем хосте относятся к TMB.

**Запрошенная команда**:
Явно заданная программа (абсолютный путь) плюс упорядоченный массив аргументов. Выполняется ровно она, без неявного shell; явно указанный интерпретатор считается обычной запрошенной командой со своим argv.
_Avoid_: командная строка, shell-строка

**Запрос**:
Структурированное обращение клиента к брокеру: запрошенная команда, рабочий каталог, целевой пользователь и уникальный nonce запроса. Запрос выражает желание агента выполнить команду на хосте; эту команду запускает брокер, а обычные команды внутри песочницы агент выполняет самостоятельно.

**Брокер**:
Привилегированный компонент TMB на принимающем хосте. Единственная точка входа агентного пути привилегированного выполнения на хосте: проверяет право запросчика, показывает человеку точный запрос для одобрения, гасит одноразовый токен и запускает одобренную запрошенную команду. Полностью ортогонален sudo: не меняет ни sudo, ни sudoers, ни PAM.

**tmb-клиент**:
Непривилегированная утилита внутри песочницы. Не выполняет запрошенную команду на хосте: строит запрос, передаёт его брокеру, возвращает вывод и код возврата.
_Avoid_: считать клиента исполнителем команды

**Песочница**:
Изоляция агента в OpenShell: агент не имеет ни root, ни sudo, ни произвольного доступа к принимающему хосту; привилегированное выполнение на хосте доступно через точку входа TMB. Обычный сетевой доступ агента определяется политикой OpenShell и не требует посредничества TMB.

**Одобрение**:
Решение человека по точному запросу: запрошенная команда, рабочий каталог и целевой пользователь показываются человеку целиком до выполнения. Без одобрения выполнения нет; диалог агента доказательством не считается.
_Avoid_: считать ask-диалог агента гарантией безопасности

**Одноразовый токен**:
Подтверждение одобрения, привязанное к одному точному запросу, с коротким сроком жизни. Действует максимум на одну попытку запуска и не гарантирует завершения команды.
_Avoid_: сертификат, пропуск

**Погашение токена**:
Переход одноразового токена в использованное состояние до запуска команды. Погашение однократно, нераздельно (атомарно) и переживает перезапуск компонента; повторное предъявление, гонки и переигровка отклоняются.
_Avoid_: считать погашение обратимым или гарантией завершения команды

**Fail-closed агентного пути**:
Свойство TMB: при любой неисправности компонентов TMB агентный путь закрывается, а обычный парольный sudo человека, ssh и ОС хоста продолжают работать нетронутыми.

**Обычный sudo**:
Привычный парольный путь: sudo спрашивает пароль человека. Отдельная дорожка, TMB её не заменяет, не меняет и не расширяет.

**Журнал**:
Летопись брокера: кто запросил, что именно, когда, какое решение принял человек и чем выполнение закончилось. Не шлюз, а запись.

**Точка входа TMB**:
Канал из песочницы к брокеру: TCP-endpoint, разрешённый отдельным сетевым правилом OpenShell для tmb-клиента. Это путь к привилегированному выполнению на хосте; обычный трафик агента регулируется другими сетевыми правилами.
_Avoid_: escape hatch, дырка в песочнице

**Идентичность запросчика**:
То, чем брокер узнаёт просителя: uid из SO_PEERCRED на локальном пути хоста, отпечаток клиентского сертификата на пути песочницы. Одна и та же сущность в allowlist, журнале и одобрении.
_Avoid_: IP-адрес, «просто соединение»

## Сертификаты канала песочницы

**Удостоверяющий центр TMB (CA)**:
Корень доверия канала песочница→брокер: подписывает сертификат брокера и сертификаты песочниц. Подпись CA допускает к соединению, но не даёт права просить.
_Avoid_: считать подпись CA разрешением

**Сертификат песочницы**:
Клиентский сертификат, выданный CA одной песочнице и живущий внутри неё. Предъявляется брокеру при каждом соединении; его отпечаток и есть идентичность запросчика на пути песочницы. Кто получил выполнение внутри песочницы, тот и проситель.
_Avoid_: сертификат агента, сертификат пользователя

**Сертификат брокера**:
Серверный сертификат, выданный CA на имя точки входа TMB. Клиент проверяет его до отправки запроса, чтобы не говорить с подменённым брокером.
_Avoid_: pinning по отпечатку

**Отпечаток**:
Однозначный идентификатор открытого ключа песочницы. Представляет песочницу в allowlist, журнале и на консоли одобрения; переживает перевыпуск сертификата на тот же ключ и меняется только со сменой ключа.
_Avoid_: fp без расшифровки, отпечаток сертификата, серийный номер, CN

**Allowlist**:
Перечень идентичностей запросчика, которым разрешено просить: uid для локального пути хоста, отпечатки для пути песочницы. Проверяется до показа одобрения; подпись CA в него не входит.
_Avoid_: список допущенных, список CA, список IP

## Политика запроса

Границы, внутри которых запрос вообще допускается к одобрению; проверяются до показа человеку, нарушение отклоняется без одобрения.

**Корни cwd**:
Перечень каталогов, внутри которых разрешён рабочий каталог запроса. Рабочий каталог оценивается по разрешённому пути (realpath), а не по строке запроса.
_Avoid_: считать рабочий каталог свободным параметром

**Политика окружения**:
Правило, какое окружение получит запрошенная команда: фиксированные переменные задаёт брокер и запрос их не меняет; переменные запроса допускаются только по перечню ключей. Человеку показывается итоговое окружение, а не окружение запроса.
_Avoid_: наследование окружения брокера, PATH из запроса

## Одобрение вне консоли

**Одобряющий**:
Человек, которому разрешено решать по запросу. Отдельная роль со своим перечнем идентичностей: запросчик не одобряет, одобряющий не просит. Доверенный подписант и удалённое одобрение это варианты одобряющего.
_Avoid_: смешивать с запросчиком, «админ»

**Очередь одобрений**:
Запросы, прошедшие политику и ждущие решения одобряющего. Запрос ждёт решения ограниченное время, затем отклоняется; отключение запросчика снимает запрос с очереди.
_Avoid_: считать очередь хранилищем одобрений

## Будущие термины

Понятия будущих этапов (#2, #3); контракт полей сохранён как основа.

**Доверенный подписант**:
Планируемый доверенный фронтенд одобрения на Mac: показывает человеку точный запрос и после касания Touch ID выпускает подписанное разрешение. В первой версии одобрение показывает сам брокер.

**Подписанное разрешение**:
Планируемая авторизация ровно одной запрошенной команды для конкретного принимающего хоста и пользователя выполнения, переносимая по каналу между Mac и хостом: уникальный идентификатор запроса, время выдачи и короткий срок годности, максимум одна попытка запуска.
_Avoid_: сертификат, force-command
