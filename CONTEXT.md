# TMB

Глоссарий Tool Mediation Broker: словарь посредничества между агентом и привилегированным выполнением команд. Здесь зафиксированы договорённости о смысле слов, а не факты об уже написанном коде; деталей реализации нет.

## Language

**TMB (Tool Mediation Broker)**:
Брокер между агентом (opencode) и привилегированным выполнением команд: агент просит, человек одобряет, запрошенная команда выполняется ровно один раз. Неофициальная расшифровка: «trust me brother».

**Запрошенная команда**:
Явно заданная программа (абсолютный путь) плюс упорядоченный массив аргументов. Выполняется ровно она, без неявного shell; явно указанный интерпретатор считается обычной запрошенной командой со своим argv.
_Avoid_: командная строка, shell-строка

**Запрос**:
Структурированное обращение клиента к брокеру: запрошенная команда, рабочий каталог, целевой пользователь и уникальный nonce запроса. Запрос - единственный способ выразить желание агента; сам агент ничего не исполняет.

**Брокер**:
Привилегированный компонент TMB на принимающем хосте. Единственная точка входа агентного пути: проверяет право запросчика, показывает человеку точный запрос для одобрения, гасит одноразовый токен и выполняет ровно одну запрошенную команду. Полностью ортогонален sudo: не меняет ни sudo, ни sudoers, ни PAM.

**tmb-клиент**:
Непривилегированная утилита внутри песочницы. Ничего не исполняет: строит запрос, передаёт его брокеру, возвращает вывод и код возврата.
_Avoid_: считать клиента исполнителем команды

**Песочница**:
Изоляция агента на принимающей стороне: агент не имеет ни root, ни sudo, ни произвольного доступа к хосту; единственный канал наружу - точка входа TMB. Слой изоляции и транспорт приняты в ADR 0003.

**Одобрение**:
Решение человека по точному запросу: запрошенная команда, рабочий каталог и целевой пользователь показываются человеку целиком до выполнения. Без одобрения выполнения нет; диалог агента доказательством не считается.
_Avoid_: считать ask-диалог агента гарантией безопасности

**Одноразовый токен**:
Подтверждение одобрения, привязанное к одному точному запросу, с коротким сроком жизни. Действует максимум на одну попытку запуска и не гарантирует завершения команды.
_Avoid_: сертификат, пропуск

**Погашение токена**:
Переход одноразового токена в использованное состояние до запуска команды. Погашение однократно, нераздельно (атомарно) и переживает перезапуск компонента; повторное предъявление, гонки и переигровка отклоняются.
_Avoid_: считать погашение обратимым или гарантией завершения команды

**Fail-closed агентного пути**:
Свойство TMB: при любой неисправности компонентов TMB агентный путь закрывается, а обычный парольный sudo человека, ssh и ОС хоста продолжают работать нетронутыми.

**Обычный sudo**:
Привычный парольный путь: sudo спрашивает пароль человека. Отдельная дорожка, TMB её не заменяет, не меняет и не расширяет.

**Журнал**:
Летопись брокера: кто запросил, что именно, когда, какое решение принял человек и чем выполнение закончилось. Не шлюз, а запись.

**Точка входа TMB**:
Единственный разрешённый канал из песочницы к брокеру: TCP-endpoint, разрешённый ровно одним сетевым правилом песочницы; весь остальной исходящий трафик закрыт.
_Avoid_: escape hatch, дырка в песочнице

**Идентичность запросчика**:
То, чем брокер узнаёт просителя: uid из SO_PEERCRED на локальном пути хоста, отпечаток клиентского сертификата - на пути песочницы. Одна и та же сущность в allowlist, журнале и одобрении.
_Avoid_: IP-адрес, «просто соединение»

## Сертификаты канала песочницы

**Удостоверяющий центр TMB (CA)**:
Корень доверия канала песочница→брокер: подписывает сертификат брокера и сертификаты песочниц. Подпись CA допускает к соединению, но не даёт права просить.
_Avoid_: считать подпись CA разрешением

**Сертификат песочницы**:
Клиентский сертификат, выданный CA одной песочнице и живущий внутри неё. Предъявляется брокеру при каждом соединении; его отпечаток и есть идентичность запросчика на пути песочницы. Кто получил выполнение внутри песочницы, тот и проситель.
_Avoid_: сертификат агента, сертификат пользователя

**Сертификат брокера**:
Серверный сертификат, выданный CA на имя точки входа TMB. Клиент проверяет его до отправки запроса, чтобы не говорить с подменённым брокером.
_Avoid_: pinning по отпечатку

**Отпечаток**:
Однозначный идентификатор конкретного выпущенного сертификата. Представляет сертификат песочницы в allowlist, журнале и на консоли одобрения; меняется при любом перевыпуске.
_Avoid_: fp без расшифровки, серийный номер, CN

**Allowlist**:
Перечень идентичностей запросчика, которым разрешено просить: uid для локального пути хоста, отпечатки для пути песочницы. Проверяется до показа одобрения; подпись CA в него не входит.
_Avoid_: список допущенных, список CA, список IP

## Будущие термины

Понятия будущих этапов (#2, #3); контракт полей сохранён как основа.

**Доверенный подписант**:
Планируемый доверенный фронтенд одобрения на Mac: показывает человеку точный запрос и после касания Touch ID выпускает подписанное разрешение. В первой версии одобрение показывает сам брокер.

**Подписанное разрешение**:
Планируемая авторизация ровно одной запрошенной команды для конкретного принимающего хоста и пользователя выполнения, переносимая по каналу между Mac и хостом: уникальный идентификатор запроса, время выдачи и короткий срок годности, максимум одна попытка запуска.
_Avoid_: сертификат, force-command
